## 2. Key Learnings

### Sigil is the source of truth for conversation history
- Use `sigil_query` with `operation: search_conversations` and explicit `from`/`to` timestamps (RFC3339 UTC) to scope retrieval to a rolling 24-hour window.
- `list_conversations` without filters returns the most recent 50 conversations across all time, not just today — always pass a time range for digest use cases.
- Conversation titles in Sigil default to the conversation UUID unless explicitly set; this makes topic identification difficult without fetching each conversation's generations.

### GitHub MCP commit pattern
- `push_files` is preferable to `create_or_update_file` for new files: it does not require a prior SHA lookup.
- Always target a specific branch (`main`) explicitly — do not rely on defaults.
- File path convention established: `daily-digests/YYYY-MM-DD.md` using the user's **local date** (America/New_York), not UTC, to match business-day boundaries.
