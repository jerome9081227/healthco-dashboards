## 2. Key Learnings

- **Sigil monitors external apps, not Assistant itself.** The Grafana AI Observability (Sigil) tool tracks LLM traffic for applications you instrument — it does not index Grafana Assistant's own chat sessions. To get retroactive session content, you need to either (a) instrument your own LLM app with the Sigil SDK, or (b) set up a webhook/automation that logs each Assistant session to Loki or another store.
- **GitHub MCP is live and functional.** The `push_files` tool successfully creates new paths and files in a single commit. No pre-existing SHA is needed for new files.
- **Automation + GitHub MCP = persistent knowledge.** Scheduling this prompt as a nightly Grafana Assistant Automation (cron `0 23 * * *`) creates an automatically growing knowledge base in the repo without manual effort.

## 3. How Enterprise Customers Use This at Scale

### Daily Digest Automation
Large enterprises run scheduled Assistant automations that aggregate activity across multiple teams. The digest is committed to a shared monorepo with folder-per-team structure (`daily-digests/<team>/<date>.md`). Pull request summaries are auto-generated from the diffs, giving engineering managers a weekly roll-up without any manual reporting.

### GitHub MCP as a Knowledge Pipeline
Enterprises treat the GitHub MCP as a one-way write channel: Assistant generates structured artifacts (runbooks, post-mortems, configuration snapshots), and GitHub provides version history, blame, and searchability. This replaces ad-hoc Confluence pages with auditable, diff-able Markdown.

### Sigil for LLM Governance at Scale
For teams shipping AI-powered products, Sigil is configured with evaluation rules and guards that run on every conversation. At scale this means: automated quality gates on LLM output, cost-per-conversation tracking broken down by team label, and anomaly alerts when token usage or error rates deviate from a 7-day baseline. The same alert contact points used for infrastructure (PagerDuty, Slack) receive LLM quality alerts.

### Automation Governance
Enterprises scope automations to `tenant` visibility so ops teams can share standard daily checks (error rate summaries, SLO status, capacity reports). Role-based access (Assistant Admin) controls who can create tenant-scoped automations vs. personal ones. Audit trails come from the Grafana audit log.

### Skill Libraries as Institutional Memory
Enterprises maintain a `tenant`-scoped skill library with runbooks, architecture diagrams, and prompt templates. New engineers onboard by asking Assistant questions; answers are grounded in the skill library rather than tribal knowledge. Skills are version-controlled by periodically exporting them via API and committing to a repo.
