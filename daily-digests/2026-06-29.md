## 2. Key Learnings

1. **The Daily Learnings skill is a bootstrap pattern.** On first run (or when no prior tool-accessible history exists), the active session becomes the digest source. This is correct behavior — the workflow establishes itself through use.

2. **Sigil ≠ Grafana Assistant conversation history.** Grafana AI Observability tracks conversations from LLM apps you instrument via the Sigil SDK. Grafana Assistant's own chat is a different surface. Don't query Sigil expecting to find your own Grafana Assistant sessions there.

3. **GitHub MCP is live and production-ready.** `mcp_github-push_files` commits Markdown (or any content) atomically to any permitted repo in a single tool call. No SHA required. This makes AI-generated documentation workflows trivial to automate.

4. **Skill invocation resolves correctly end-to-end.** "Run the Daily Learnings skill" in Grafana Assistant correctly triggers `search_skills` → `manage_skills read` → executes instructions. No manual lookup or copy-paste required.

5. **`push_files` > `create_or_update_file` for new files.** When creating a new file, `push_files` is simpler — no SHA lookup step, handles atomicity, and supports batching multiple files in one commit.

6. **Automations cannot call `manage_automations`.** This is a deliberate safety guard. Automation-triggered runs block recursive automation management. Design automation prompts to not require listing or modifying other automations.
