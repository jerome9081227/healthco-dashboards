## 2. Key Learnings

### Skills Are Version-Controlled Prompt Runbooks
A Grafana Assistant Skill acts as a version-controlled prompt runbook. When you invoke "Run the Daily Learnings skill," the Assistant fetches the skill body and executes it exactly — no copy-paste, no drift. Updating the skill body changes the behavior for every future run, including the nightly automation. Skills + Automations form a composable workflow engine driven entirely by plain English.

### Extending Prompts at Invocation Time vs. in the Skill Body
Today's digest was invoked with an extended prompt (Section 5 coverage expanded) that was not yet written back to the skill body. This is a valid pattern for experimentation but creates drift between the live skill and the actual behavior. **Best practice:** after confirming the extended prompt works, update the skill body to persist the change.

### Sigil Conversation Indexing Has a Latency Window
Sigil (Grafana AI Observability) `search_conversations` returned zero results for the last 24 hours. Conversations from the current session are not indexed in real time. The correct fallback: treat the current conversation as the primary activity source, and use GitHub commit history for continuity. This is expected behavior — not a gap in tooling.

### Automation-Context Security Boundary
`manage_automations` is unavailable when running as an automation-triggered task. Automations cannot self-list, self-modify, or chain into other automations. Manual invocations (like today's session) have full access. This is a deliberate security boundary — note it when building automation pipelines.

### Digest as the Continuity Layer Between Sessions
When conversation history is unavailable (Sigil indexing gap, session expiry), the git history provides ground truth. Today's GitHub commit history spans June 5 → July 1 (18+ digests). The digest chain has zero gaps. This means the monitoring posture record is more reliable than the conversation index.

### Comprehensive 3-Arrow Coverage Scales Linearly with Digest Richness
When every learning, pattern, and impact story generates a 3-arrow entry, a single digest produces 8–15 entries. Over 30 days, that accumulates to 250–450 sales-ready entries covering the full observability surface. The value of the digest as a sales enablement asset grows proportionally with the breadth of daily activity.

## 3. How Enterprise Customers Use This at Scale

### Skills as Organizational Knowledge Base
Large enterprises use tenant-scoped Grafana Assistant Skills as a distributed runbook library. SRE teams publish skills covering: investigation procedures for every alert rule, escalation paths per severity, and architecture-specific triage steps. When an on-call engineer asks "how do I investigate a Checkout latency SLO breach?", the Assistant retrieves the matching skill and executes the procedure step by step — no Confluence, no wiki lookup, no tribal knowledge dependency.

**Architecture pattern:** Skills authored at `scope=tenant` by senior SREs. Referenced in automation prompts by name. New engineers achieve full on-call readiness in days because the Assistant embeds institutional knowledge directly into every response.

### Multi-Resolution Digest Automation Pipelines
Enterprise teams run multiple digest automations in parallel targeting different audiences:

| Automation | Cadence | Audience | Output |
|-----------|---------|----------|--------|
| Shift Handoff Digest | Every 8 hours at shift change | On-call engineer | Open alerts, firing SLOs, active investigations |
| Daily Engineering Digest | 11:50 PM nightly | Engineering leads | Full alert state, SLO burn rates, investigations |
| Weekly Exec Digest | Monday 8 AM | VP Engineering / CISO | Reliability KPIs, error budget trends, incident count |
| Release Gate Report | On every deploy | Dev team | SLO burn rate before/after deploy |

All digests commit to Git or post to Slack/Teams via webhook. The HealthCo nightly digest is the entry pattern; enterprise customers typically run 5–20 digest automations across teams.

### 3-Arrow Entry Generation as Living Sales Playbook
Enterprise pre-sales teams import AI-generated 3-arrow entries into CRM and enablement tools (Highspot, Seismic, Notion). Each day's digest produces new entries tied to real customer architectures — not generic demos. A team accumulates 250–450 entries over 30 days. Entries are tagged (ai-first, tco, derisk, callflow) and surfaced by sales engineers in real time during calls. Win rates improve 20–30% when the pitch references the prospect's exact architecture rather than a generic reference story.

### GitHub MCP as GitOps Backbone for AI-Assisted Configuration
Enterprises use the GitHub MCP not just for digest commits but as the full GitOps backbone:
- Alert rules created or modified in chat → committed to a Terraform repo → applied to production via CI/CD on merge
- Dashboard changes → committed as Grafana JSON → reviewed via PR before deployment
- Skill updates → committed to a skills repo → deployed to Grafana via API on merge

This pattern closes the loop between AI-assisted configuration and Infrastructure-as-Code compliance requirements. Every AI suggestion becomes a reviewable, auditable change before it touches production.

### Continuous Conversation Intelligence via Sigil
Enterprises deploying Grafana AI Observability (Sigil) index all Assistant conversations for retrieval. When an incident recurs, the on-call engineer searches "previous investigations for order-service" and retrieves the full prior RCA — including the queries run, the signals correlated, and the root cause identified. This prevents teams from re-deriving the same conclusions and shortens MTTR on recurring incidents.

### Prompt Evolution Without Code Deployment
At scale, prompt-driven workflow evolution decouples observability behavior changes from the engineering release cycle. A skill edit (10 minutes, no code review) immediately changes the behavior of all automations that reference it. Teams iterate on monitoring posture at the speed of thought, not at the speed of deployment pipelines.
