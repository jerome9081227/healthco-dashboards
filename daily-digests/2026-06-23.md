## 3. How Enterprise Customers Use This at Scale

### SLO Burn Rate Alerting
Large healthcare organizations instrument hundreds of services with Grafana SLOs using a standard architecture:
- **Service-level folders** per clinical domain (cardiology, oncology, radiology, pharmacy) with team-scoped RBAC
- **Federated Prometheus** per cluster, remote-writing to a centralized Grafana Cloud stack
- **Two-tier burn rate alerts** routing differently: `Very High` pages on-call via PagerDuty; `High` sends a Slack digest to the owning team
- **Error budget dashboards** refreshed every 5 minutes, linked to runbooks in the Grafana Assistant skills knowledge base
- Alert rule sets provisioned via Grafana Terraform Provider from a central config repo (e.g., `healthco-dashboards`)

### Golden Signals at Scale
Enterprise SRE teams automate golden signal coverage via:
- Template-based alert provisioning per service — reducing per-service config time from hours to minutes
- Thresholds maintained in a central config repo and applied via CI/CD pipeline
- `traffic-absent` alerts as the first line of defense against silent failures (dark services producing no telemetry)
- Cardinality-controlled label sets: services use `job`, `namespace`, and `service_name` to avoid label explosion at 100+ services

### Frontend Observability Maturity Model
Enterprise customers move through three phases:
1. **Error count alerting** — current HealthCo state
2. **Core Web Vitals alerting** (LCP, FID, CLS per route) — partially in place
3. **Session replay + RUM-to-trace correlation** — Faro session data linked to backend Tempo traces for full patient journey debugging

### GitHub MCP + Automated Digest Pattern
Platform engineering teams use Grafana Assistant automations + GitHub MCP to:
- Auto-commit daily observability snapshots to infrastructure-as-code repos
- Generate PR descriptions with observability evidence when deploying service changes
- Produce HIPAA/SOC 2 audit evidence via committed, timestamped markdown reports
- Create weekly SLO budget status reports auto-posted to Slack and committed to Git

### Skills / Runbook Lifecycle at Scale
Mature platform teams maintain 50–200 Grafana Assistant skills:
- Triage runbooks per alert rule (linked by rule UID in alert annotations)
- Architecture documentation per clinical service
- Oncall handoff templates auto-populated by the nightly digest automation
- Runbook content reviewed quarterly; stale skills archived and replaced via the settings UI
