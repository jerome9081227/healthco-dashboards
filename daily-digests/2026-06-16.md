## 3. How Enterprise Customers Use This at Scale

### SLO-Driven Alerting Architecture
**Multi-Team Ownership:**
- **Platform SRE** owns SLO definitions, recording rule infrastructure, and burn rate thresholds
- **Service teams** own SLI queries (e.g., "what counts as a successful checkout?") and error budget policy
- **On-call engineers** receive burn rate alerts through contact points, routed by service label

**Federated SLO Management:**
- Large enterprises run **100+ SLOs** across teams using folder-based RBAC
- SLO templates stored as JSON/Terraform for consistency (e.g., "2h/1h burn rate for 99.9% SLO")
- Recording rules deployed to **dedicated rule evaluation tenants** to isolate SLO calculation from production Prometheus

**Volume Considerations:**
- Each SLO generates **~15 time series** (recording rules + metadata)
- 100 SLOs = 1,500 series, trivial cardinality for Grafana Cloud
- Alert evaluation every 1 minute (default) — sub-second query performance required

### GCP Infrastructure Monitoring at Scale
**Multi-Cluster / Multi-Project Setup:**
- **One Grafana stack** per business unit, querying multiple GCP projects via Cloud Monitoring datasources
- Alert rules use `project_id` label to route notifications to team-specific contact points
- CloudSQL alerts **per-instance** — large deployments monitor 50+ database instances with dynamic alert generation

**Operational Workflows:**
- **Database SRE team** owns CloudSQL/Pub/Sub alerts, uses Assistant for "show me all lagging replicas" queries
- **Incident response** starts with SLO burn rate alert → drills into GCP infrastructure alerts → correlates with application logs/traces
- **Capacity planning** uses the same metrics (CPU, memory, disk) in dashboards with 90-day retention

**Compliance & Audit:**
- **HIPAA/SOC 2** requires monitoring of database connection attempts, replication lag, and audit log ingestion
- Alert rules capture "AbortedConnections" as a security signal (potential brute force)
- **Retention policies** store alert state history in Loki for 1+ year
